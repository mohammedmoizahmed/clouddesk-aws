How CloudDesk works

What happens behind the scenes when you raise a ticket.

1

You raise a ticket

Describe the problem and attach a screenshot if you have one.

2

It is stored safely

The ticket goes into a database on its own storage volume. The screenshot goes into a private storage bucket.

3

Files are checked

A serverless function checks the file type and size, then records the result.

4

Support resolves it

The status moves from Open to In Progress to Resolved.

CloudDesk is a learning project built on AWS with EC2, EBS, S3, Lambda, DynamoDB and Docker.
